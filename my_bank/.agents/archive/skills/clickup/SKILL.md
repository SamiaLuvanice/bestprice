# ClickUp opcional

Use somente quando `.agents/sources.md` e `harness.yaml` declararem a integração
do projeto atual. Leia os IDs e listas da configuração; nunca use valores
copiados de outro projeto.

Credenciais devem vir do conector MCP ou do ambiente. Não registre tokens,
senhas ou dados privados em skills, specs ou commits.
