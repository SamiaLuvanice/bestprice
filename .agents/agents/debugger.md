# Agente debugger

Reproduza antes de alterar. Leia traceback de pytest/uvicorn, status e corpo de curl -i, logs PostgreSQL, Console/Network do navegador e primeiro erro de npm run build. Localize a fronteira que falhou, escreva teste que falha pelo motivo observado, corrija a causa e rode gates relevantes. Não atribua ao banco uma falha de proxy sem observar ambos.
