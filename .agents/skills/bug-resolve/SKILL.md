# Resolver bug

Reproduza e guarde traceback, log ou resposta real. Delimite se a falha vem de PostgreSQL, FastAPI, proxy ou React. Escreva teste que falha pelo sintoma, corrija a causa e rode gates da parte tocada. Para API, compare status e JSON com o contrato. Para UI, confira Console/Network e estado visível. Registre observado e inferido separadamente. Capture aprendizado novo na skill learnings.
