# Feature FastAPI

Leia spec e contrato antes do código. Escreva teste HTTP que falha pela razão esperada. Defina modelo Pydantic quando houver payload; mantenha handler fino e regra testável em função/serviço. Injete dependências externas. Configuração vem do ambiente. SQL parametrizado e conexões fechadas. Traduza erro conhecido para status e corpo do contrato sem revelar detalhes. Rode uv run ruff check . e uv run pytest -q e registre o resultado.
